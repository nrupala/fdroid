Step by step

  1. Install F-Droid from f-droid.org if you don't have it yet. It's a free app store for open-source Android apps.
  2. Open F-Droid and go to Settings → Repositories.
  3. Tap the + button and enter this address: https://fdroid.aimlds.org/repo
  4. Tap Add. F-Droid may show a fingerprint — it should match the one below.
  5. Go back to the home screen, search for Vault Tracker, and install it. Updates will arrive through F-Droid from now on.
